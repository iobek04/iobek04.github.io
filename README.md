# Ipek Naz Obek — Personal Research Website

This is a simple static website designed for GitHub Pages.

## Files

- `index.html` — main website
- `styles.css` — visual styling
- `profile.jpg` — add your headshot using this exact filename
- `Ipek_Obek_CV.pdf` — add your CV using this exact filename

## Before publishing

1. Replace `YOUR-GITHUB-USERNAME` in `index.html`.
2. Update the Boston University/lab link.
3. Add your real email address if needed.
4. Add `profile.jpg`.
5. Add `Ipek_Obek_CV.pdf`.
6. Add links to any demos, posters, or repositories.

## Publish with GitHub Pages

1. Create a repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/root`.
6. Save.

Your site will appear at:

`https://YOUR-GITHUB-USERNAME.github.io`
